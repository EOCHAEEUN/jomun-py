# 법률 QA 답변 정확도·근거 충실성 1차 평가

2026-10-08. 이 문서는 `/ask`가 실제로 생성한 답변을 법령 원문과 대조한 **AI 검토자의 1차 감사**다. 변호사 또는 독립된 사람의 검수 결과가 아니다.

## 실행 조건

- 평가 질문: 새로 작성한 10개(`data/eval/qa_heldout.jsonl`), 일반 질문 5개·서비스 설명 질문 5개. 질문과 기대 조문·필수/금지 주장은 답변 생성 전에 고정했다. 기존 개발용 QA 12문항은 쓰지 않았다.
- 모델: MonoRouter 경유 `gpt-4.1`, temperature 0. Qdrant QA 인덱스 395개, 인공지능기본법 2026-07-21 PDF와 시행령 2026-08-20 PDF. 문항당 답변 1회 생성.
- 원자료: `docs/qa_heldout_answers_20261008.json`, 문항별 주장·출처 대조: `docs/qa_review_20261008.json`.
- 검색 결과: `docs/qa_heldout_search_20261008.json`. 서비스 문항은 질문과 서비스 설명을 합쳐 검색하며, 답변 생성도 같은 서비스 설명을 받는다.

## 채점 기준

1. **전체 답변 정확**: 질문별 `must_include`를 충족하고, 적용 조건·의무 강도를 바꾸거나 근거 없는 새 의무를 확정하지 않으면 통과. 인용 누락은 별도 근거 점수로 기록하되, 법적 의무를 필수라고 새로 단정한 경우는 전체 답변도 실패로 처리한다.
2. **근거 부족 주장**: 반복을 합친 독립적인 사실 주장마다 실제 인용한 조문 또는 질문에 제시된 서비스 사실을 대조한다. 법적으로 참이어도 **인용한 출처가 그 주장을 뒷받침하지 않으면** `uncited`로 센다. 조문과 반대되는 주장은 `contradicted`로 센다. 따라서 이 비율은 허위 사실 발생률과 동일하지 않다.
3. **제외**: 질문 자체의 사실이 법령상 판정 기준을 충족하는지 판단할 수 없으면 답변 정확도 분모에서 제외하고 사유를 남긴다.

분모가 우연히 모두 9개지만 **서로 다른 문항 집합**이다. 검색 지표는 정답 조문이 없는 개인정보보호법 자동 면제 질문을 빼고, 기준일이 불충분한 해외 사업자 질문을 포함한다. 답변 지표는 그 반대로 채점한다.

제외한 문항의 답변도 확인했다. 모델은 기준 시점을 “전년도 3개월간”이라고 부정확하게 표현하고 현재 제시된 150만 명만으로 국내대리인 지정·신고를 확정했다. 시행령 제29조①은 **전년도 말 기준 직전 3개월간 국내 이용자 수의 하루 평균 100만 명 이상**을 규정한다. 평가 질문의 결함을 결과를 본 뒤 고치면 별도 평가의 의미가 없어지므로 이 문항을 그대로 보존한다.

## 해석과 한계

- 기존 QA 12문항의 검색 Hit@3 100%는 답변 정답률이 아니다. 이번 검색 가능 문항 9개에서는 정답 조문 **하나 이상**을 상위 3개에서 찾은 것이 8개였지만, 필요한 근거를 모두 상위 5개에서 찾은 것은 5개였다. 관련 조문을 찾은 뒤에도 **필수 조항을 빠뜨리거나 다른 조항을 인용하지 않고 새 의무를 말한** 사례가 있었다.
- 9개 유효 문항은 매우 작고 사람이 시나리오를 골랐다. 이 **55.6%를 실제 사용자 질문에 대한 정확도나 법률 자문 신뢰도로 일반화할 수 없다**.
- 위 채점은 Codex가 저장된 답변과 프로젝트의 원문 PDF/청크를 대조한 것이다. 발표나 실서비스 신뢰도 수치로 사용하려면, 법률 검토자 2명이 같은 기준으로 독립 채점하고 불일치를 조정한 뒤 더 큰 새 평가셋으로 다시 측정해야 한다.

재현: `python -m scripts.evaluate_qa --gold data/eval/qa_heldout.jsonl --stages hybrid_rerank --answers --output <답변 파일>`은 API 키와 QA 인덱스가 필요하며 새 답변을 생성한다. 저장된 답변의 검토 수치는 `python -m scripts.score_qa_review`로 다시 계산한다.
